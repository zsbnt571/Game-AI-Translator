# 截图翻译界面测试器 0.2.6-test

基于 0.2.1-test 的最小修复版本。保留原截图、OCR候选和预览窗口架构。

## 本轮修复

- API 请求次数在发送前立即更新，失败、超时、取消和解析错误也记录耗时。
- 状态栏显示整理段落、组装请求、发送、HTTP响应、读取、解析、排版和最终状态。
- 连接超时 10 秒，翻译完整流程总超时 60 秒。
- 保存翻译任务，重新翻译会取消并等待旧任务结束。
- 安全日志写入程序目录的 `logs\translation.log`，不记录 API Key。
- 先探测 `response_format=json_object`；明确不支持时只回退一次无该参数请求。
- 支持顶层 ID 对象、`translations` 包装对象、数组和 Markdown JSON 代码块。
- 同一自然段的视觉行改为自然连接；不同段落仍双换行。
- 标题、正文、时间、消息数量和短按钮保持独立区域。
- 保存原始 OCR 行和矩形到 `OcrDocument.RawLines`。
- 翻译过程中不再显示空的 `[p001]`、`[p002]` 占位符。

## 构建

```powershell
dotnet build -c Release
```

此项目仍是独立测试器，不修改游戏 AI 翻译器、MGITranslator、稳定版或正式游戏目录。
