## Distribution gate / 发布边界

The [machine-readable policy](docs/redistribution-policy.json) is the audit record; it is not yet wired into an installer. Existing local payload archives are excluded, including mixed archives that could contain otherwise open-source dependencies. Before a future Release, enumerate the actual payload, match every component/version to a permitted entry, retain its notices and satisfy source/relinking obligations. Any unknown file blocks that package. Do not publish the current local build outputs as a ready-to-distribute installer.

[机器可读政策](docs/redistribution-policy.json)是审查记录，尚未接入安装包生成程序。现有本地混合 ZIP 均排除；即使其中部分组件开源，也不能整包直接发布。以后发布前须逐项对照实际包内文件与版本、保留声明、满足源码/重新链接等义务；未知文件阻止该包发布。当前本地构建输出不能直接作为可再分发安装包上传。

Full version/source evidence is in [the dependency inventory](docs/third-party-dependencies.json), [the local input manifest](docs/local-dependencies.json) and retained upstream notices. Legal texts/authors must not be removed to hide internal testing details.
