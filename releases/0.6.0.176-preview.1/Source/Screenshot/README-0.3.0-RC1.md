# 截图翻译界面测试器 0.3.0 RC1

## 定位

本版是以 `0.2.10-ui-polish-test` 为唯一代码基线整理的正式候选版，没有继承 `0.2.11`、`0.2.12`、`0.2.13` 的段落合并、VisualTextBlock 或 VisualContainer 实验。

当前推荐用法是：**查看原图，并在右侧查看完整文字译文**。

## 默认行为

- 图片默认显示“原图”。
- 文本默认显示“译文”。
- 翻译完成后，右侧显示完整译文。
- 不自动生成、不自动切换译图。
- “译图（实验）”只在用户主动选择时生成；生成失败不影响右侧文字翻译。

## 保留能力

- Windows 本地 OCR，OCR 原文不可变。
- `deepseek-v4-flash`、`thinking.type=disabled`、`stream=false`。
- 紧凑 JSON 单次批量请求；同一截图一次翻译只发出一次 API 请求。
- 首字节超时、完整请求超时、取消与非模态错误处理。
- 重新翻译不重新 OCR。
- 多个 PreviewForm 各自保留图片、OCR、译文、CTS、状态和高亮。
- 原图/OCR原文/整理后原文/译文切换，以及复制文字、复制图片和保存图片。

## 已知限制

- 译图仍属于实验功能，复杂布局下可能出现分组、字号、遮盖或位置不理想；它不是本候选版的推荐输出方式。
- Windows OCR 可能出现 `o/O/0` 混淆、图标被识别为字符、小字遗漏或混合语言识别不完整。
- PaddleOCR 分支已经暂停，本版不要求安装任何新 OCR 组件。
- 网络和服务端负载仍会影响 API 响应时间。

## 基线记录

- `0.2.8-speed-fix-test`：速度修复基线。
- `0.2.10-ui-polish-test`：本候选版的代码基线，也是目前视觉效果相对最好的译图实验基线。
- `0.2.11`～`0.2.13`：失败的段落合并实验，不作为本版或后续正式版本基线。
