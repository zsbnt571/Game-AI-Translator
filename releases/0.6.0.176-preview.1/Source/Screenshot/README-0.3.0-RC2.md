# 截图翻译界面测试器 0.3.0 RC2 Capture UX Test

本版以已通过人工验收的 `0.3.0-rc1` 为稳定功能基线，只优化截图覆盖层交互、绘制和资源释放。

- 右键或 Esc 可在任意截图阶段取消，不创建预览、不执行 OCR 或翻译。
- 已有选区支持整体移动和八方向缩放，裁剪始终使用进入截图模式时取得的同一张冻结画面。
- Move/Resize 使用局部脏区和双缓冲重绘，不把边框、工具栏或尺寸文字写入冻结画面。
- 本次闪屏修复移除了主窗口隐藏后的固定 160ms 空窗期；冻结图在 Overlay 可见前准备，首帧直接绘制冻结桌面和遮罩。
- 原图＋右侧完整译文、RC1 翻译协议、多 PreviewForm 和实验译图保持不变。

这是“闪屏修复人工候选”，不替代已验收的 RC1。自动环境不能可靠执行真实桌面 `CopyFromScreen`，仍需在真实 4K 显示器完成下列验收。

## 4K 人工验收清单

1. 连续进入并退出截图 20 次，确认无明显整屏闪烁。
2. 确认不出现黑屏、白屏、桌面先亮后暗或 Overlay 空白首帧。
3. 右键取消与 Esc 取消。
4. 新建选区。
5. 选区内部整体移动，确认无残影。
6. 四边和四角分别缩放，确认无残影。
7. 快速来回移动和快速缩放。
8. 移动后确认截图，核对裁剪位置。
9. 缩放后确认截图，核对裁剪尺寸。
10. 取消后再次截图。
11. 多个 PreviewForm 保持不受影响。
