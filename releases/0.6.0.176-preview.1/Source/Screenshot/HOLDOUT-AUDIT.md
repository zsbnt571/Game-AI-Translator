# Holdout audit

The fixed historical evidence set is regression-only.

Set A and Set B were rejected as final holdout evidence because the fixture assigned long body translations to compact labels and the initial metric compared tight glyph ink with container width. Their failures are retained for transparency.

No product threshold or sample-specific layout branch was added for those failures. The observation model and fixture roles were corrected, then a new Set C with different geometry and aspect ratios was generated and evaluated once as the final holdout set.

Set C was not used to tune product layout parameters. Status remains Manual Acceptance Pending.
