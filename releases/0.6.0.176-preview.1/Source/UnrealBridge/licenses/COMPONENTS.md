Build: publish Source/UnrealCatalog for win-x64 with self-contained runtime into Build/Fusion-R1-0.6.0.81/UnrealCatalog, prepare the owned runtime archive with prepare-unreal.ps1, then build Source/Screenshot. The catalog project explicitly includes and hash-checks the existing Oodle dependency from Source/UnrealCatalog/Native so clean publishes retain it. Runtime compatibility is established by per-launch native roundtrip checks, not by recognizing an engine name alone. Version 0.6.0.81 retains these same third-party component versions and adds necessary structural preflight checks for generic UE4.22–4.27 candidates; these checks alone do not establish successful runtime loading or visible translation.

Version 0.6.0.83 keeps the same loader, font assets, catalog worker and third-party bytes. This maintenance build retains the .81 self-contained catalog worker in Build/Fusion-R1-0.6.0.83/UnrealCatalog; Work/Fusion-R1-0.6.0.83/prepare-unreal83.py repacks only the reviewed main.lua and fonts.lua changes from the .82 archive before the desktop build. Version 0.6.0.84 retains the same third-party loader, font assets and self-contained .81 catalog worker. Version 0.6.0.85 adds Fusion-owned text_api.lua and updates main.lua/runtime.lua for reflected, read-only text-query signature checks and diagnostic failure stages. Work/Fusion-R1-0.6.0.85/prepare-payloads85.py retains the .84 vendor loader, fonts and all other entries byte-for-byte, with only this one reviewed archive addition.
