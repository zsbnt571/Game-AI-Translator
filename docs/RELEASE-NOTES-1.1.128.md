# Fusion 1.1.128 更新说明

Fusion 是面向 Windows x64 的游戏翻译工具，提供支持引擎的游戏内翻译、截图 OCR 翻译、游戏库和可选游戏工具。本版汇总自公开 **1.0.0** 以来的主要更新。

## 从 1.0.0 到现在更新了什么

- **补齐九种界面语言：**简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语和俄语。新配置默认跟随 Windows，不支持的系统语言回退英语；调整语言列表顺序后仍保留原选择。界面语言与游戏目标翻译语言独立。
- **扩展资源读取和预翻译：**改进支持格式中的 RPG Maker、Ren'Py、Unity/Naninovel、Godot、WOLF 和网页引擎文本读取，包括可获取的对白、选项、角色名和界面文本。优先复用已有译文，实时翻译补充遗漏。
- **改进缓存命中并减少重复请求：**更好地处理玩家名字变量、重复使用的文本控件和进行中的请求；迟到译文会核对当前原文。进度与重试更明确地区分完成、排队和失败状态。
- **普通启动后控制翻译：**兼容适配器可在从 Fusion 正常启动时准备连接，随后在同一游戏进程开关翻译。普通启动不要求 API 密钥；翻译与游戏修改独立开关。
- **改进字体和显示：**支持多语言自定义字体预览、缺字检查，以及兼容适配器的实时应用和恢复默认；改进 Unity 文字测量、Godot 裁剪和姓名输入布局。默认字体继续沿用现有适配，只在主动选择后应用自定义字体。
- **改进游戏工具与速度控制：**改进各引擎专用变速、状态恢复和逐游戏隔离，包含 RPG Maker 的逻辑推进方式；改进 Ren'Py 跳过控制和连续数值修改。具体可用能力仍由引擎决定。
- **修复免密钥服务配置：**兼容服务无需再填写假密钥。可以连接已启动的 OpenAI 兼容本地模型服务，也可以配置在线翻译 API。
- **自动辅助处理性别语法：**无需增加设置。共用翻译流程可利用当前同一条英文原文中明确的性别或代词信息，辅助英、西、法、德、俄翻译；部分 Ren'Py 场景还可利用跨台词角色信息。未知或冲突时沿用正常翻译流程，并非所有引擎都已支持跨台词识别角色。

## 1.1.128 新修复

角色信息不再遮住有效普通缓存；已有译文可以直接复用，不强制重新调用 API。迟到的角色信息不再丢弃已经进行中的普通翻译请求。重试失败时保留有效旧译文、失败原因和重试记录。

新增性别辅助不改变中文、日语和韩语的翻译路径，不清空或迁移现有缓存。

## 下载与使用

下载 **Fusion-1.1.128.zip**，完整解压后运行 **GameTranslator.exe**。随包包含 .NET、Python、OCR 组件，不需要另装这些组件。在“设置 → 翻译方案”配置 API 或已经运行的本地模型服务；程序不附带大语言模型、模型服务器或服务额度。可选 Google 封面搜索使用 Windows WebView2。

**Fusion-1.1.128-Source.zip** 是开发源码附件；GitHub 自动 Source code 包不是运行程序包，且不包含全部二进制构建输入。

本版仍是预览版。动态剧情、短暂显示原文、旧字体系统、回放、地图及跳过后的速度表现仍可能受游戏实现影响。普通启动后开关翻译需要由 Fusion 建立兼容连接。详见[已知限制](KNOWN-ISSUES.md)和[验证报告](VALIDATION-1.1.128.md)。项目自有代码继续使用 GPL-3.0-only，第三方组件保留各自许可。
