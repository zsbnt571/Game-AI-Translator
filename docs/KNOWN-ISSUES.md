# FUSION R1 0.6.0.177 Preview 1 — 已知问题

• Sloppy Fields 的一次正常游玩异常退出尚未确定原因。本次修复预译准入并补充错误记录，没有证明修复闪退。
• GameMaker 预译回退仅适用于能保守推断为单语言的脚本文本，并需本次实际原文确认。混合、未确认或无法提取的目录仍可能主要依赖实时补充；预提取不是全游戏覆盖保证。
• 标准错误弹窗按游戏进程采集；闪现后立刻关闭、自绘窗口、权限限制、直接终止等情况可能无法记录。请正常保存游戏；不要为排查而删除存档或 Mod。
• 自动/单选/组合均可能误判短词、人名、纯汉字和缺少上下文的文字。未选来源保留；已有目标语言保留。已发出的请求可能在语言切换时完成。
• 本轮 245 + 756 + 22 项均为受控检查，其中包含真实游戏提取资源读取；未进行本版真实 API 质量对比、长时间游戏运行或所有引擎画面验收。此前 .176 的真实 API 结果不能当成 .177 重新验证的结果。
• Unity IL2CPP、Unreal 等引擎继续有适配限制；识别/提取成功不保证写回、字形、排版和全流程成功。已有 Mod/加载器可能触发冲突保护。
• 新目标、风格和提示词不会自动重写所有旧译文。首次翻译仍受 API 延迟、配额和模型行为影响。
• 默认 CPU 路径含本地运行依赖，API 服务、系统组件、游戏和显卡驱动需自备。可选 GPU 运行文件沿用原依赖，没有进行新的全硬件 GPU 推理验收。
• 不包含专有 Oodle 解压库，某些 Unreal 资源无法读取。其他可选重型视觉模型并非全部捆绑。
• 译图属于实验功能，复杂背景和文字排版可能出现残留或错位。没有新增全部 DPI/分辨率/主题切换的视觉验收。
• 尚未完成全新 Windows 虚拟机的完整安装验收。本机解压与运行依赖 10 组检查、Unicode 路径 15 项检查已通过；完整记录见发布附件 PACKAGE-VERIFICATION.json。
