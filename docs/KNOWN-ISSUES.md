# 已知限制

- 兼容性取决于引擎、版本和游戏实现。发现资源或进度达到完成，不代表所有动态文本都已发现并正确显示。
- 部分游戏仍可能短暂显示原文，或在控件复用、逐字显示、场景切换后漏译。
- 同进程开关翻译需要已建立的兼容连接；外部启动的游戏或旧驻留组件可能需要重新启动来建立连接。
- 字体替换和恢复因引擎而异。旧 Unity 文本系统、原生中文、复杂文字排版及部分字形显示仍有限制。
- Ren'Py 回放界面、Unity 动态剧情、WOLF 连续修改与地图，以及跳过/动画后的速度状态仍需完善兼容性。游戏修改属于实验功能。
- **自动性别语法辅助，无需额外设置。** 共用流程可利用同一条英文原文中的明确证据，辅助英、西、法、德、俄翻译；部分 Ren'Py 场景还可利用跨台词角色信息。未知或冲突时保持正常流程，目前不支持所有引擎的跨台词角色识别。
- 旧 Unity IL2CPP 集成仍使用已停止支持的 .NET 6.0.7，本次 .NET 8/10 更新没有升级该组件。

反馈问题时请提供 Fusion 版本、游戏引擎及版本、界面语言、目标语言和复现步骤。提交附件前移除 API 密钥和个人数据。[提交问题](https://github.com/zsbnt571/Game-AI-Translator/issues)。
