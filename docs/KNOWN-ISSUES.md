# FUSION R1 0.6.0.176 Preview 1 — 已知问题与测试范围


发布定位
这是公开测试版，适合愿意反馈的用户。Windows x64 主包已含默认 CPU 使用路径的本地运行依赖；“依赖齐全”不等于全部引擎、显卡和游戏均已兼容。

语言与翻译
• 已覆盖的 Ren'Py / Godot 活跃语言测试未发现未启用语言包的独有文本被批量翻译。该结论限于对应样本与采集路径，不是所有游戏的保证。
• 真正出现在当前内容里的混合文字按来源范围处理；选择英日会有意保留可识别的韩语，自动模式则可翻译它。
• 极短文本、罗马字、同形词、纯汉字、名字及缺少上下文的词仍可能判断不准，无法承诺完全没有额外 API 请求。部分较长日文名字仍有歧义。
• 游戏切换语言前已经采集的文字可能完成请求；共享菜单与语言选择项也可能同时出现。请用“未启用包独有文本”判断是否误读整包。
• 新的目标/风格不会自动替换全部旧缓存。人工译文优先，重译需在“译文与术语”主动操作并先备份。
• 已加强英文目标误回中文、短日语/韩语混合片段遗漏和结局标签的检查；自动检查不保证每一句含义、文风与排版都完美。模型、网络、限流与服务版本会影响结果。
• 本轮真实 API 数据用自然风格；不代表所有个性化风格均逐句人工验收。新的游戏翻译保护检查也不代表截图 OCR 和所有图像输入路径完成了同等回归。

游戏与显示
• MIST、Konoha：在隔离真实游戏副本运行原生菜单、语言切换与有限开场；没有完整通关。
• Village：真实主菜单检查，未完成全流程验收。
• Brotato、Chillquarium：读取真实压缩语言资源并在真实引擎宿主检验；未启动这两款商业游戏的完整可执行程序，不能宣称实机画面通过。
• 额外 RPG Maker 混合结局标题：真实资源样本，未玩到对应结局；部分混合对白也仅有资源证据。
• Unity IL2CPP、Unreal 及其他未在本轮重跑的引擎保留兼容性限制。检测/提取成功不保证运行时写回、字形与布局成功。
• 已有 Mod/加载器可能触发冲突保护；不会把强行覆盖作为默认解决办法。若中文缺字、按钮空白、原文不替换，请单独报告。
• 首次翻译可能先显示原文。在线服务耗时与缓存状态会影响体感。
• UI 已有改进，但本轮包装验证不等于所有分辨率、DPI、主题切换和下拉控件均完成新的可视化验收。

依赖与平台
• 尚未做全新 Windows 虚拟机验收。已做本机隔离解压、包内运行时启动和 OCR 健康检查，详见随发布附带的“验证结果.txt”。
• 旧辅助工具/Windows OCR 仍依赖系统 .NET Framework 4.8 与 Windows OCR 语言组件。
• 可选 NVIDIA GPU 依赖沿用已核对的旧补充包，不是新的 .176 全硬件 GPU 推理验收。显卡驱动需用户自备；不兼容时使用 CPU。
• 不含专有 Oodle。需要它的 Unreal 压缩资源可能无法提取。
• Paddle 文档布局与其他可选重型视觉模型未全部捆绑，默认路径不要求它们。
• 译图仍为实验功能，复杂背景擦除与文字布局可能有残留、错位或风格差异。
