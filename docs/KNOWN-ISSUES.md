# FUSION R1 0.6.0.178 Preview 1 — 已知问题

- 部分游戏“先方框后中文”的字形/字体现象尚未完成实际画面复现，本版不声明修复；此前 Sloppy Fields 闪退原因也仍未确定。
- 预译只覆盖提取器能够确认的基础显示文字。未启用语言包、未确认来源和未知脚本继续受保护；动态或无法提取的内容仍需实时补充。提取成功不等于整个游戏均可提前翻译。
- GameMaker 的单语言脚本回退仍需保守目录判断与本次实际原文确认。短词、人名、纯汉字及缺少上下文的文本仍可能误判。
- RPG Maker 恢复只接管精确匹配的 Fusion 组件和可核对的启动记录；其他 Mod、修改过的组件或不一致备份继续触发保护。
- 本版已完成 1,187 项受控队列、语言边界、安装恢复及兼容检查，其中 3 项为实际游戏资源只读检查。未新增真实 API 质量比较、商业游戏运行、长时间游玩或完整画面验收。此前 .176 的真实 API 证据不代表本版重新验证。
- Unity IL2CPP、Unreal 等引擎继续有兼容限制；识别/提取不保证写回、字形、排版和游戏内显示。
- 更换目标语言、风格和提示词不会自动重写旧译文；首次翻译受 API 速度、配额和模型行为影响。
- 默认 CPU 依赖随包提供。API 服务/额度、游戏、平台组件和显卡驱动需自行准备。可选 GPU 依赖沿用已发布文件，本版没有新增全硬件 GPU 推理验收。
- 专有 Oodle 与部分可选重型视觉模型不随包提供。译图仍为实验功能，复杂背景与排版可能残留或错位。
- 尚未完成全新 Windows 虚拟机、全部 DPI/主题或全引擎实玩验收。公开包的本机隔离检查与完整性记录见发布附件 PACKAGE-VERIFICATION.json。
