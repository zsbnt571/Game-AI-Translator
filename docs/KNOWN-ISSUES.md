# Fusion R1 0.6.0.179 Preview 1 — 已知问题

- “先方框后中文”尚未获得完整游戏画面验证，本版不声明已修复；Sloppy Fields 的历史闪退原因仍未确定。本轮启动连接期间未崩溃，不代表长时间游玩通过。
- 预译只覆盖能够确认来源的显示文字。Ren’Py 的原始 Say/Menu 和 Godot 的共享显示字段/当前 TranslationServer 结果获得独立来源证明；未启用语言资源、任意脚本字面量继续受保护。GameMaker 某些目录仍须等待足够的实际语言样本。
- WPF 主工作区保持现有布局、设置和服务。专业图像/文本查看器、部分引擎工具、按键录制与弹窗仍复用原控件，迁移不是全部控件重写。
- 实际桌面检查在 1024×768 环境进行。全 DPI、多显示器和全部辅助功能尚未验收。当前测试环境对 GPU 游戏窗口的截图常为黑色，未将 API 成功等同于字形、排版或完整游戏画面通过。
- 若 WPF 主界面在特定驱动/机器上异常，可关闭程序后运行附带的兼容界面启动器，或使用 GameTranslator.exe --legacy-ui。该入口保留相同数据和翻译服务，请勿同时写入同一数据目录。
- RPG Maker 恢复仅接管可由安装记录、组件与备份哈希共同证明的 Fusion 文件。修改过的组件、其他 Mod 或备份不一致继续触发保护。
- Unity IL2CPP、Unreal、Godot 3 及本轮未覆盖的版本保留兼容限制。识别/提取不保证写回、字形或游戏内显示。
- 新翻译仍受 API 速度、配额及上下文影响；更换风格/目标语言不会自动重写旧译文。译图背景处理仍为实验功能。
- 可选 NVIDIA 加速包复用 178 的原文件。本轮没有新增全硬件 GPU 推理或全新 Windows 虚拟机验收；专有 Oodle 与部分可选模型不随包提供。

验证方法、通过项及边界见 [179 验证说明](VALIDATION-179.md)。
