# 当前已知限制

基线：Fusion R1 0.6.0.85。以下区分用户反馈和已验证的实现范围，不声明全游戏支持。

- Unreal Engine：部分运行环境中画面仍保留原文。读取到文本或存在译文不能证明内嵌替换成功；当前仍有替换身份和运行时桥接缺口。
- 已有 Mod 的 Unity 游戏：`doorstop_config.ini` 等已有加载器文件可能触发安装冲突保护。此时保留原安装，不代表 Mod 功能本身一定无法共存；通用加载器复用仍待完善。
- Unity IL2CPP：部分运行环境中无法翻译。已有成功反馈不能代表整个引擎的兼容性。
- Unity Mono：存在部分中文缺字或按钮空白反馈，原因尚未确认。
- Godot：存在原文显示一段时间后才替换为译文的反馈。当前画面文字应优先处理；首次翻译仍受服务响应时间影响，个别控件还可能有字号与布局问题。
- 文本统计是提取条目数，可能包含菜单、资源字符串等，并不等于对白数量。0.6.0.85 已调整语言筛选先于条目上限，但仍需结合实际资源核验。

0.6.0.85 包含当前文本队列提升、缓存回写限量与去重等通用调整。构建/离线检查通过不代表这些反馈均已在真实游戏中复测通过。
