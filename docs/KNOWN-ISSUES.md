# Fusion R1 1.0.0 Preview 1 — 已知问题与验证边界

[English](KNOWN-ISSUES.en.md) | [Русский](KNOWN-ISSUES.ru.md) | [返回首页](../README.md)

**游戏修改仍处于实验阶段。识别引擎、读取数据、写入成功和长期游玩正常是不同验证阶段。**

## 翻译与文本范围

- 预译只覆盖可确认来源、实际读取到并属于所选语言范围的文本。运行时生成的内容、图片内文字、自定义绘制、未知封包和部分脚本仍可能遗漏。100% 只表示当前已发现范围完成。
- Ren’Py 和 Godot 已改善符合条件的原始显示文本采集；这不保证覆盖全部隐藏控件、插件或未启用语言资源。GameMaker 的部分资源仍需要足够的实际语言证据。
- WOLF 资源、配对数据库、深层目录采集和部分定制逐字显示已有修复；定制逐字显示依赖已验证的资源组合，不能推广到所有版本。某些当前显示中的句子可能要重新显示或重启后才能使用新译文。
- 对少量残留原文或名称不一致，软件优先保留可用译文并有限补救。达到重试上限后自动请求会停止；需要在译文管理中查看原因。格式、数字、占位符损坏或只有解释/拒答仍不作为有效正文。
- 自动名称识别依赖来源证据。特殊称谓、同名不同对象、多语言别名和短词仍可能判断错误；普通单词不应套用为所有语境的固定译法。人工更正和导入规则保留，需要自行核对已有冲突。
- 改变风格、指令或目标语言不等于批量重写所有旧缓存。不同目标语言分别管理；修改名称后的相关自动译文更新也需要处理时间。
- 新译文依赖 API 延迟、额度和模型结果。API 返回成功不等于字形、换行、画面显示或游戏剧情语义已经验收。历史上出现过的方框显示、显示延迟及部分游戏退出反馈，不能由本轮界面检查宣称全部解决。

## 游戏修改——实验阶段

- 常用金钱、角色属性、关系、CG/回想等分类可能包含需要核对的候选。字段名称有提示作用，但不能单独证明其真实用途；不会自动进行全部回想解锁。
- 仅展示实际可读取的类别。不同游戏的结构不同，WOLF、RPG Maker、Ren’Py、Unreal 等不会因此具备相同功能。Unity IL2CPP、Unreal、Godot 3 和本轮未覆盖版本仍有兼容限制。
- WOLF 当前调速接口为 0.25–100×，RPG Maker MV/MZ 为 1–100× 整数加速。100× 是可请求的倍率，不保证实际速度、音画同步或长时间稳定；其他引擎未统一支持。调速不改变 Fusion 的界面帧率。
- RPG Maker 可用图标继续显示；WOLF 通用图标映射不完整。地图只展示可读取的格点和事件，不是完整地图贴图或编辑器。
- 分类切换和后台刷新保留选择、滚动和未提交输入，但大型数据库首次收集/名称准备仍可能较慢。已修复复现过的卡顿和重复键错误，不保证所有游戏的等待都已消失。
- 修改前保留游戏存档备份。运行时改动不一定写入存档；读档、切换对象或游戏重建数据后，可能需要重新刷新。锁定、撤销及保存范围取决于具体接口。
- RPG Maker 组件恢复只接管可由安装记录、组件与备份哈希共同证明的 Fusion 文件。其他 Mod、修改过的组件或备份不一致仍触发保护。

## 界面、性能与依赖

- 本版不承诺稳定 60 FPS；高分辨率最大化仍可能明显变慢。减少重绘、封面缓存和分类缓存改善的是已定位路径，不等于全场景物理帧率保证。
- 英语/俄语检查覆盖了近期新增的实际 WPF 控件、动态文字、窄窗和语言切换。游戏译文由所选目标语言控制；界面翻译不代表已经逐一验证所有游戏中的俄文字体与排版。
- 专业查看器、辅助工具和兼容入口可能仍使用既有控件或平台组件，WPF 更新不等于全部底层组件重写。
- 若当前机器出现 WPF 显示问题，可关闭 Fusion 后以 `GameTranslator.exe --legacy-ui` 使用兼容入口。不要同时启动两个版本写同一数据目录。
- 截图 OCR、译图背景处理和游戏内翻译覆盖不同内容；译图背景处理仍为实验功能，可能存在背景或布局瑕疵。
- 可选 NVIDIA 加速依赖沿用 178 资产，没有新增全硬件推理验收。专有 Oodle、部分重型可选模型和用户显卡驱动不随包提供。旧辅助功能仍依赖 Windows 平台组件。
- 没有宣称完成全新 Windows 虚拟机、全部 DPI/主题/多显示器、辅助功能或全部引擎长期实玩验收。

## 本次构建检查

本次发布构建完成 **613 / 613 项受控检查，全部通过**，包含 342 项界面与语言检查和 271 项修改/翻译回归检查。这些结果不等于真实游戏长期游玩或物理屏幕帧率验收。

历史检查不能直接替代本次发布构建检查；受控测试、资源检查、真实控件截图和实际游戏运行分别记录。详细改动见 [三语更新说明](RELEASE-NOTES-1.0.0.md)。

反馈时请提供版本、引擎、界面/目标语言和复现步骤，并去除日志里的密钥与个人信息。无需公开上传游戏或存档。
