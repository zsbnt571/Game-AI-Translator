# FUSION R1 0.6.0.176 Preview 1 使用说明


一、下载与启动
普通用户选择 Fusion-0.6.0.176.zip。Source code 和 source ZIP 供开发者阅读与构建，不能当作可执行程序运行。
完整解压后运行 Fusion-R1/GameTranslator.exe。程序、runtime、tools、adapters 等目录必须一起保留。选择有写入权限的目录，预留至少 5 GB 可用空间；游戏库封面、截图历史与翻译缓存会继续占用空间。
面向 Windows 10/11 x64；本版未做全新 Windows 虚拟机验收。不提供 macOS、Linux 或 ARM 原生包。

二、API 方案与翻译内容是两套独立设置
当前入口：设置 → 翻译方案。
上面的 API 方案保存接口地址、API 密钥、模型和连接超时。填写完整后先“测试连接”，再“保存方案”；测试连接不会代替保存。
下面“翻译内容”独立保存目标语言、原文范围、风格、用户提示和文字保护选项。改完点击“保存翻译内容”。
同一内容设置可配合不同 API 方案。切换 API 不会把目标语言、组合或提示词换回另一套。
截图翻译与游戏翻译共用已保存的翻译内容。新截图任务使用新设置；正在运行的游戏应退出后重新以翻译模式启动。
旧配置首次迁移时以原公共默认方案初始化共享内容，原方案记录保留；迁移后请核对一次目标语言、组合、风格。
软件界面语言与翻译目标语言独立。例如英文界面可以译成中文，中文界面也可以译成日文。

三、自动、单选、自选组合怎样取舍
自动识别：适合不确定原文语言或会夹杂多种语言的游戏。根据采集到的实际文字处理非目标语言，操作少；极短词、同形词、名字、纯汉字和资源键可能不够明确，少量内容仍可能进入模型判断。
单选一种：例如只选英语，明确限制英语为翻译来源，其他已识别语言默认保留。适合只要翻英语、不希望夹杂的日语/韩语被翻译的用户；也会有意漏过真正出现的其他语言。
自选组合：下拉框选“自选组合”，勾选一种或多种语言，至少保留一种。适合英语正文中夹日语等明确场景；未选语言的片段默认保留。退出时在同一下拉框改选自动或单一语言，再次进入会记住组合。
多选没有“第一语言/第二语言”的主副顺序，勾选位置不会设定优先级。游戏实际启用的语言与已显示的文字决定采集内容，组合决定其中允许翻译哪些语言。

四、游戏有英日韩语言包，但只启用英语，会发生什么
游戏语言包是否参与采集，与 Fusion 的源语言选择是两件事。
在本轮覆盖的 Ren'Py 和 Godot 活跃语言采集场景中，仅使用游戏当前语言相关内容；未启用的语言包独有文本没有被批量送去翻译。
因此选自动或英日组合，均不等于主动翻译该游戏整套未启用的日语/韩语语言包。游戏界面只显示英语时，英日组合中的“日语”只是允许翻译真正出现的日语片段。
但游戏自己把多国语言选项、双语对白、字幕或共用菜单同时显示出来时，这些是实际内容。自动模式会考虑非目标语言；组合模式只处理所选来源。纯语言选项名称与已有目标语言通常保留。
不能把上述结果推广为所有引擎、所有插件或资源预翻译工具绝不多采集。某些游戏预构建隐藏控件，尚未出现于屏幕的文字也可能被引擎读取。资源目录提取/整库预翻译的范围可能大于当前画面。
游戏切换语言瞬间，先前已观察到并发出的请求可能完成；这不表示另一套未启用语言包被全量读取。

五、用三个目标语言理解混合内容
目标中文，原文英日组合：实际出现的英文、日文可翻；已有中文保留；可明确识别的韩语保留。
目标英文，原文英日组合：英文已经是目标语言，默认保留；日文可翻成英文；韩语保留。
目标日文，原文英日组合：日文保留；英文可翻成日文；韩语保留。
换成自动识别时，实际出现的韩语也进入可翻范围。界面语言不会改变这些规则。
真实混合句按语言片段保护：已是目标语言、未选来源、ID/代码、变量等应保留；可翻片段才变化。
不要为了“减少翻译量”把真正需要翻译的语言取消勾选；不确定时先用自动，遇到明确误判再限制来源。

六、翻译风格与提示词
自然：优先表达顺畅和原文语气，适合作为通用选择。
游戏化：按对白、任务、技能和菜单调整表达，强调角色语气、玩法信息和术语一致性。
本地化：按上下文处理文化梗、比喻和表达习惯，保留真实名称与故事背景，不全局替换品牌或国籍。
文艺化：在适合的叙述中增加语言韵味，不补造事实、情绪或意象。
自定义：依据自己的提示词调整；留空时仍要求准确自然。
直译（旧方案）：兼容原有选择，偏向原文措辞和结构。
所有风格都以准确为先。菜单、短按钮和技术标签往往会得到相同译文，风格差异更常出现在长对白或叙述。四字词/成语只是表达工具，不是目标。
用户提示可补充任何风格。例如“对白口语化；任务目标简洁；保留人名”。不要在提示词中写入 API 密钥等秘密。
切换风格不自动清空已有译文。需要对比时，在“译文与术语”对相同内容重译；先备份人工译文，避免把缓存结果误当成新风格。
本次 258 行真实 API 复测使用自然风格，验证语言范围与保护边界，不代表每一种个性化风格都经过相同规模的真实语义审校。

七、游戏内翻译
导入或选择游戏 → 确认该游戏的 API 方案 → 按页面提供的安装/翻译启动入口操作。
检测到引擎只是接入判断；提取、生成译文、游戏加载和实际显示是不同阶段。以游戏中的实际画面和页面状态为准。
首次请求依赖网络和服务速度，可能先显示原文，缓存命中后通常更快。有效缓存和人工修订会保留。
已有 Mod、加载器、汉化补丁的游戏先用备份副本验证；出现冲突保护时不要强行覆盖。
普通启动不会自动启用翻译。只想读文字或准备资源时，不能把缓存生成成功当作游戏内已显示译文。
截图翻译可作为未接入引擎的替代方式，但不改变游戏文件内的文字。

八、截图翻译与 OCR
进入顶部“截图翻译”发起截图；快捷键以“设置 → 按键”为准。RapidOCR 和默认识别模型已在主包中。
“设置 → 截图处理”的识别语言影响从像素读字；“翻译内容”的原文语言影响读到的文字是否翻译。这两个设置用途不同。
预览可以看原图、识别文字与译文；“启用译图”为实验功能，复杂背景、字体、竖排、描边和小字可能不理想。
默认 OCR 在本机运行。文字翻译发送到你选定的 API 服务；若主动改用图像输入或视觉服务，对应图片也会按该功能设置发送。
需要离线工作时，可配置兼容的本地翻译服务；本包没有附带通用大语言模型或免费云端额度。

九、数据、升级与回退
本包没有个人 API 方案、游戏库、历史截图或存档。首次启动在程序旁创建 data。
升级前关闭 Fusion 与相关游戏，备份旧版实际数据目录，完整复制到新程序的 data。旧版设置中若用自定义位置，以“存储位置”显示的实际目录为准。
不要让新旧程序同时写同一目录，不要把旧 runtime、tools 或 exe 覆盖进新包。只迁移用户数据。
启动后核对库、目标语言和连接；密钥可能因 Windows 账号/设备加密而需要重填。
保留旧程序和升级前数据备份。回退时使用备份，不让旧程序直接读取已经被新版迁移的数据。
单个游戏中的翻译桥接是否需更新，以软件提示为准。不要手动删除游戏内已有 Mod 或存档来“修复”翻译。
公开分发请使用未使用过的原始 ZIP，不要重新压缩自己的 data。

十、遇到问题如何反馈
报告版本、Windows 版本、游戏/引擎版本、目标语言、原文范围、问题出现的步骤，以及一小段原文/译文或截图。
说明是“看见未选语言被翻译”“未启用语言包独有内容被采集”“原文未替换”还是“OCR 识别错误”，有助于定位不同环节。
日志先检查并移除密钥、令牌、个人目录、私密对白及其他敏感内容。无需上传游戏本体或存档。
已知范围与未验收部分见“已知问题.txt”；依赖与可选 GPU 安装见“依赖说明.txt”。
