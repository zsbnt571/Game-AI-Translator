# Fusion 1.1.128 — изменения

Fusion — инструмент для Windows x64: перевод внутри поддерживаемых игр, OCR-перевод снимков экрана, библиотека игр и дополнительные игровые инструменты. Этот выпуск объединяет изменения после публичной версии **1.0.0**.

- Девять языков интерфейса: упрощённый и традиционный китайский, английский, японский, корейский, испанский, французский, немецкий и русский. Новые настройки следуют языку Windows; для неподдерживаемых языков используется английский. Сохранённый выбор языка не меняется после перестановки списка. Язык интерфейса отделён от языка перевода игры.
- Расширено чтение ресурсов и предварительный перевод для поддерживаемых форматов RPG Maker, Ren'Py, Unity/Naninovel, Godot, WOLF и веб-движков. Уже сохранённые переводы используются в первую очередь.
- Улучшены повторное использование кэша, обработка имён игрока и повторно используемых элементов текста; уменьшено число повторных запросов. Исправлены отдельные случаи обработки запоздавших результатов, прогресса и повторных попыток.
- Поддерживаемые игры, запущенные через Fusion, могут подготовить соединение при выключенном переводе и затем переключать перевод без перезапуска процесса. Обычный запуск не требует ключа API. Перевод и изменение игровых значений управляются отдельно.
- Добавлены многоязычный просмотр пользовательских шрифтов, проверка отсутствующих символов, применение и восстановление на совместимых адаптерах. Улучшены измерение текста Unity и обрезка/поля имени Godot. Стандартная адаптация шрифтов сохранена.
- Улучшены управление скоростью, восстановление состояния и изоляция игр, включая специализированные пути RPG Maker, пропуск текста Ren'Py и последовательное изменение значений.
- Исправлена работа совместимых сервисов без ключа API. Можно подключить работающий локальный сервер модели с OpenAI-совместимым API.
- Автоматическая помощь с грамматическим родом не требует дополнительных настроек. Общий путь перевода использует явные английские сведения в пределах одного исходного элемента для английского, испанского, французского, немецкого и русского перевода. Ограниченный контекст персонажей между репликами поддерживается в Ren'Py. Неопределённые или противоречивые сведения не меняют обычный путь. Это не полное распознавание персонажей во всех движках.

В **1.1.128** сведения о персонаже больше не скрывают подходящий обычный кэш и не отменяют уже выполняющийся обычный запрос. Неудачная повторная попытка сохраняет пригодный старый перевод и сведения об ошибке. Помощь с родом не меняет китайский, японский и корейский пути перевода; кэш не очищается и не переносится.

Скачайте **Fusion-1.1.128.zip**, полностью распакуйте и запустите **GameTranslator.exe**. .NET, Python и OCR входят в комплект. Настройте API или работающий локальный сервер модели; сама модель, сервер и оплаченные запросы не входят в комплект. Необязательный поиск обложек Google использует Windows WebView2.

Это предварительный выпуск: совместимость динамического текста, шрифтов, повторов сцен, карт и скорости зависит от игры. См. [ограничения](KNOWN-ISSUES.ru.md) и [проверки](VALIDATION-1.1.128.md). Собственный код проекта остаётся под GPL-3.0-only; сторонние компоненты сохраняют свои лицензии.
