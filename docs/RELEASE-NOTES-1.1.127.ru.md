# Fusion 1.1.127 — Изменения

Выпуск включает изменения после публичной версии 1.0.0.

- Интерфейс на девяти языках, выбор системного языка для новых настроек и сохранение выбранного языка после перестановки списка.
- Улучшены обнаружение ресурсов, предварительный перевод, обработка повторных запросов и выдача точных совпадений кэша в поддерживаемых адаптерах.
- Улучшено управление переводом после обычного запуска, независимыми состояниями игр, нормальным выходом и отдельным разрешением изменений игры.
- Улучшен выбор и возврат пользовательских шрифтов с сохранением стандартной адаптации.
- Добавлено ограниченное согласование рода по контексту Ren'Py: требуется известный говорящий и явное английское свидетельство пола или местоимений. Целевые языки: английский, испанский, французский, немецкий и русский. Это ещё не автоматическое определение пола для всех движков. Китайский, японский, корейский и обычный кэш не меняют прежний путь.
- Совместимые сервисы без ключа больше не требуют фиктивного ключа.
- Соответствующие встроенные среды обновлены до .NET 8.0.33 и 10.0.14.

Распакуйте **Fusion-1.1.127.zip** целиком и запустите **GameTranslator.exe**. .NET, Python и OCR входят в комплект. Провайдер перевода настраивается отдельно; необязательный поиск обложек Google использует Windows WebView2.
