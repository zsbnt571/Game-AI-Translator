# Fusion 1.1.127 更新说明

本版包含自上次公开 1.0.0 版本以来的更新。

- 补齐简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语和俄语界面。新配置默认跟随系统，语言列表调整顺序后仍能正确读取原有选择。
- 改进支持引擎的资源发现、预翻译、重复请求处理和精确缓存投递；尚未准备的文本由实时翻译补充。
- 改进普通启动后的翻译控制、各游戏独立状态、正常退出处理及独立的游戏修改开关。
- 改进自定义字体选择和恢复，保持现有默认字体适配。
- 新增有限的 Ren'Py 角色性别语法辅助，需要已确认的说话角色和明确英文性别或代词信息，作用于英、西、法、德、俄目标语言。它尚不是跨引擎自动性别识别；中文、日语、韩语及普通缓存保持原流程。
- 修复兼容的免密钥 API 配置，不再需要填写假密钥。
- 将相关随包运行库更新至 .NET 8.0.33 和 10.0.14。

下载 **Fusion-1.1.127.zip**，完整解压后运行 **GameTranslator.exe**。随包的 .NET、Python、OCR 组件不需另装；翻译服务需自行配置，可选 Google 封面搜索使用 Windows WebView2。
