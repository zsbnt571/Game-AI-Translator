# Известные проблемы и сохранённый список — 1.1.0.127

Сохранены исходные 24 номера с обновлением состояния до 125–127. Некоторые пункты имеют ограниченные исправления: список не называет все проблемы полностью неисправленными и не заменяет проверку настоящих игр частичными результатами. Исправления относятся к общим процессам и адаптерам движков, а не к отдельным названиям игр или репликам.

## Границы обновления сред выполнения

Обновление .NET 8/10 охватывает шесть мест: приложение, помощник обложек, UnitySchema, UnrealCatalog и отдельные копии GameMaker в исходном и исполняемом пакетах. UnityEmbeddedIl2Cpp64.zip и тот же загрузчик внутри основной сборки по-прежнему содержат .NET 6.0.7. Эта среда больше не поддерживается и не исправлена данным обновлением. Она сохранена для совместимости со старым загрузчиком; замена на другую основную версию не выполняется. Обновление шести мест .NET 8/10 не означает обновления всех встроенных сред. Повторные проверки после обслуживания учитываются отдельно.

## Приостановленные работы и общие ограничения

Углублённое исследование сбоя FLife2 остаётся приостановленным. Новая сборка или публикация не возобновляет его автоматически. Причина необъяснённого сбоя не назначается без доказательств.

Скорость находится в разделе изменения игры → Общие и требует явного разрешения для этой игры. Перевод включается отдельно. Высокие множители, фиксированные шаги, анимация, медиа и диалоги с обязательным нажатием могут не ускоряться пропорционально. Схема WOLF — не живая карта.

Текущая помощь с родом ограничена надёжными статическими привязками Ren’Py и явными английскими высказываниями. Неизвестные, противоречивые или динамические данные, а также источники с нерешёнными проблемами на начало сеанса сохраняют прежний путь. Для китайского не добавляется настройка, обычный кэш массово не очищается.

В цикле 127 запущено 0 оригинальных игр и выполнено 0 запросов API перевода. Итоговая выборка 126 подтвердила 8 конкретных ожиданий; 2 случая неизвестного адресата — только наблюдения. Две ошибки первого раунда сохранены. Исторические проверки не являются повторной приёмкой 127.
