## 178 Russian Preview 1

Based on **0.6.0.178**. Adds **Russian software UI** and **Russian as a translation target**, with independent settings. A fresh installation still starts in Simplified Chinese.

- Interface: Settings > General > Interface language > Русский > Save settings.
- Translation target: Settings > Translation profiles > Translation preferences > Russian > Save preferences.
- For the initial Chinese UI: 设置 → 软件通用 → 界面语言 → Русский → 保存设置。
- Download **Fusion-0.6.0.178-Russian-Preview1.zip**, fully extract it into a new folder, and run **GameTranslator.exe**. Configure your own translation API.
- The matching **Fusion-0.6.0.178-Russian-Preview1-Source.zip** contains the complete public source and build materials. GitHub's automatic Source code archives are for developers.
- No personal API keys, game library, translation history, personal settings, games or saves are included.

**Validation:** 1,847 Russian UI resource entries checked, including placeholders; independent interface/target save and reload checks passed. The Russian UI was opened. **In-game Russian translation has not been tested**, including fonts and wrapping. Reports of translation working only in real time still need game retesting; this preview does not claim to fix them.

**179 remains withdrawn and is not part of this release.** The original [178 Preview 1](https://github.com/zsbnt571/Game-AI-Translator/releases/tag/v0.6.0.178-preview.1) remains available. The unchanged optional [178 NVIDIA GPU add-on](https://github.com/zsbnt571/Game-AI-Translator/releases/download/v0.6.0.178-preview.1/Fusion-0.6.0.178-GPU.zip) can still be used for screenshot background processing.
