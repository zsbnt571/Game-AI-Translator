# Fusion R1 1.1.0 Preview 3（build 127）

版本：1.1.0.127  
发布标识：1.1.0-preview.3+dialogue.5  
标签：v1.1.0-preview.3+dialogue.5

[English](RELEASE-NOTES-1.1.0.127.en.md) · [Русский](RELEASE-NOTES-1.1.0.127.ru.md)

这份说明汇总上一公开版本 v1.0.0-preview.1 之后到 build 127 的主要用户可见变化。中间的本地候选和历史测试不是多次公开发布，也不会累计成新版本已实测游戏的数量。

## 更早拿到文字，更少重复请求

资源读取、预翻译和精确缓存命中继续优先，实时翻译负责补漏。Ren’Py补充所选语言缺译时的源文回退、明确菜单/退出提示、安全格式文字和静态角色名称；单个节点失败不会直接结束整个目录读取。Unity增加Naninovel剧情与只读字段来源，改进玩家名展开模板、复用控件及迟到译文的身份核对。Godot扩大脚本文字与导入资源读取，修复部分裁剪与原文恢复；RGSS、网页类、GameMaker和WOLF的资源文字路径也得到补充。

共用队列减少已经准备好的名称和正文的重复请求，复用适用的单数字短标签，并继续区分目标语言、术语与显式重译。字体暂未就绪不再自动变成重复模型请求。

125加入、126继承的Godot流程在开启前分批确认精确缓存，再开启翻译。生产主机和真实Godot中性场景覆盖已有/冷缓存、控件复用、完整原文逐字显示及关闭再开；该场景中修复前首个已启用帧为原文，修复后命中缓存。这不证明Towns Charm完整剧情或任意超大缓存都能逐句首帧命中，未预装内容仍走普通补漏。

## 启动、翻译、修改各自有明确状态

各页面使用一致的启动、返回、重启和正常退出入口；无法确认进程身份或已有多个候选实例时，不随意选择目标。不同游戏的连接和状态保持隔离，正常退出可以被游戏自己的保存提示拒绝，不强制杀进程。

支持的普通启动流程会准备关闭状态的翻译接入，不因此自动预翻译或要求密钥。接入完成后可在同一进程开关翻译；外部启动而未加载组件、旧组件仍驻留及部分引擎能力仍有限制。更新组件需要正常退出旧进程，与每次普通开关都必须重启不是一回事。

修改须明确授权，打开页面或切换分类不会自动授权。速度位于“游戏修改 → 常用”，遵循当前游戏的修改开关；关闭修改会请求恢复1×，翻译开关独立。支持的Unity/Godot/Construct及RPG适配器使用各自接口或逻辑步进，改进输入草稿、确认状态、游戏暂停/快进/动画后的倍率保留和多实例恢复。固定步长、视频、音频、联网等待及需点击的对白不保证同比例加速。

## 字体保持默认适配，可主动更换和恢复

默认继续使用现有适配，不因加入字体选择而全局更换。支持每游戏系统字体或字体文件、任意文字预览和缺字提示；支持的适配器可在运行中应用并恢复默认。选择失败保留原选择和当前有效显示。

Unity旧TMP的测量污染、过度缩小和部分名称/正文显示已有局部修复；Godot的裁剪祖先判断及不能绘制时恢复原文已有中性引擎证据。MansionDays原生中文破字、其他毛边/缺笔画、旧Unity自定义图集和复杂文字塑形仍未全部解决。更换默认字体不是这些问题的验收办法。

## 九语界面、免密钥服务和自动角色语法

界面补齐简体中文、繁體中文、英语、日语、韩语、西班牙语、法语、德语、俄语，涵盖主界面、设置、弹窗、错误、托盘、工具提示和辅助阅读名称。新配置跟随系统，不支持时回退英语；保存过的选择保留，旧配置无语言字段时保留历史兼容行为。界面语言与目标翻译语言独立，用户名称、路径和原文不当作界面文案改写。127统一语言顺序，并按稳定语言值选择、保存、重载，避免位置变化导致选错语言。

无需密钥的兼容服务可以在空密钥下使用，不要求填写假值；地址和模型仍须有效。本地模型需要自行部署并启动服务。部署研究不是内置模型管理、模型训练或新后端已经集成的证明。

自动角色语法无需新增操作。当前可靠来源是Ren’Py标准角色的静态唯一绑定与明确英文自述/代词证据，向英语、西语、法语、德语和俄语请求提供有限语法信息。未知、冲突、动态绑定或不适用来源保持旧路径；不按姓名、外观猜性别，也不把说话者身份套给未知受话者。

简体/繁体中文、日语、韩语沿用原路径。新角色译文存入独立、有版本区分的缓存；普通缓存、有效旧译文及旧角色缓存保留。会话开始已有未解决问题的来源继续原失败/重试流程，不清记录假装成功。

## 失败记录和仍未解决的问题

进度更明确地区分已发现文字、待请求、排队和待写入；100%只覆盖已发现范围。通用质量规则减少变量、控制符、代码标识符的误报，保留错误原因、次数和可用旧译文。

Towns Charm的组件说明旧缓存可以经新规则复判并保留历史收据，**这不是API重新翻译**；赞助名单仍保留软失败及4次尝试。没有“两条都成功重译”的证据。

[完整24项台账](KNOWN-ISSUES.md)继续保留：原游戏偶发漏译、跨引擎同进程开关、字体、Ren’Py回放闪关、旧缓存术语补收录、Unity动态覆盖、WOLF连续改值/地图和速度/焦点等边界。Yes, Master!异常位置已定位，但0xC0000005根因未确认、未修复；不归因Fusion或游戏。FLife2深入闪退调查继续暂停。完整译文导入/分享、未来平台和外部工具研究不作为本次新增已集成功能。

## 自包含运行时维护

公开包已为六处.NET 8/10运行时应用8.0.33/10.0.14修补：主程序、封面辅助、UnitySchema、UnrealCatalog，以及程序包和完整源码中各自保留的GameMaker工具。GameMaker业务代码与其他第三方组件不因运行时服务而重编译。旧Unity IL2CPP加载器内的.NET 6.0.7单列为未升级兼容性边界，不声称已解决其停止支持问题；最终公发DLL在随包.NET 8.0.33隔离宿主上通过332项界面与852项共用宿主检查，公开包另通过2项启动/重读；不将旧检查重复累计。
